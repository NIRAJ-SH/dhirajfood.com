## 🌟 About The Project

This project is a static, responsive landing page for Dhiraj Food, designed to showcase the brand's premium product lineup, company history, and contact details. It is built using pure HTML and CSS with a modern, elegant, and user-friendly interface.

## ✨ Features

- **Responsive Design**: Flawless layout on desktop, tablet, and mobile devices.
- **Hero Section**: Engaging banner with a clear call to action.
- **Product Gallery**: Grid display showcasing 35+ premium products like Cashews, Almonds, Pistachios, and spices.
- **About Us Section**: The story behind Dhiraj Food, founded in 2000 by Shree Bhagwan Sah.
- **Contact Info**: Integrated Google Maps link, direct WhatsApp chat, and Social Media links (Facebook, Instagram, TikTok).

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom styles, responsive Flexbox/Grid layouts, and smooth hover effects.
- **Google Fonts**: [Poppins](https://fonts.google.com/specimen/Poppins) for a clean, modern typography experience.
- **Font Awesome**: Scalable vector icons.

## 🚀 Getting Started

To view the website locally, simply clone the repository and open the `index.html` file in your preferred web browser.

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Open the project folder:
   ```bash
   cd dhirajfood.com
   ```
3. Double-click on `index.html` to open it in your browser.
